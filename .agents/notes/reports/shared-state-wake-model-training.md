# Report: Shared-State Doubao Wake-Word Model Evaluation

**结论：** 共享类别变体降低了评估集上的相近词接受数，但也降低真人正例召回，并在 `s2b` 纯音乐样本出现 3 次触发。它没有替代 v5。本报告涵盖 macOS 离线实验，不含设备部署或现场验收。

本轮 B 方案在 macOS 离线训练和评估，不访问设备、不重新录音。模型仍判定完整“豆包豆包”，保持原厂 10 pdf 输出及 BINN 容器；声学 pdf 从位置独立 `[1,2,4,5,6,7,8,9]` 改为 `[1,2,4,5,1,2,4,5]`。完整 6+6+12 epochs 训练与评估已完成。阈值 0 下，相近词接受率降低，但 s3 召回下降、音乐仍有误触发，不能替代 v5 作为本轮的优选模型。

## 模型结构与实现核对

`tools/wake-train.py` 新增可选 `--shared-keyword`，默认仍使用原有独立类别。没有外部单词次数计数器。

- **Forced alignment**：仍有 bg-before、8 个关键词位置、bg-after 共 10 个状态。重复的是 emission 的 pdf 索引，不是状态；按状态回溯再映射到 pdf。正例重对齐两次，真人片段允许完整关键词重复出现。
- **FST/TransitionModel**：保留原厂 10 状态、19 arc 的图。8 个前进 arc 的 transition-id 为 `[4,6,10,12,4,6,10,12]`，自循环为 `[3,5,9,11,3,5,9,11]`；只有第 8 个前进 arc（8→9）输出最终关键词标签 4。7 帧不能到达关键词末态。TransitionModel 仍保留 10 pdf 和 20 个转移概率；共享类别的两遍聚合统计状态持续时间。
- **Prior / unused pdf**：pdf 6–9 不再有目标标签，但保持输出维度兼容。其平滑计数原本会产生极小 prior，减 prior 后抬高未使用输出；共享模式将它们的 log-prior 钳到最稀少的已使用类别。它们也没有 FST 引用，不会成为判醒路径。未标注 pdf 的转移时长取已使用类别时长中位数；独立类别默认仍保持原来的 fallback 2 帧。
- **前缀负例**：豆、豆包、豆包豆对应的相同声学片段仍标共享 pdf，首个不同字之后标 garbage。这不能再教出“第一遍/第二遍”的位置声学差别，完整两遍由图中 8 步要求。难例挖掘只遍历 train 且排除 homophone。
- **边界**：图要求 8 个状态，但没有每个状态最短时长约束；单个词被异常快速切成两遍状态仍可能误判，需要相近词评估检验。共享类别也仍有原厂 40 帧左上下文，不能宣称声学完全与位置无关。

短烟测：D96 随机特征、4 个样例、1 epoch，完成真实训练、导出和 BINN 重读；639597 B，Torch/NumPy 最大差 `1.9073486e-06`。另实测重复类别 forced-align、8 mandatory forward arcs、前缀标签集合与 unused prior 钳位通过。这是管线验证，不是识别效果。

## 结果与决策

阈值 0：B 的 dev 相近词接受率为 33/191（0.173），低于 v5 的 44/191（0.230）和 v7 的 41/191（0.215）；但 dev 正例从 v7 的 27/38 降为 25/38，s3 从 26/58、23/35 降为 22/58、17/35。s2b 仍有 3 次音乐事件，s2 为 0。共享类别降低部分相近词混淆，但没有改善音乐误激活，召回也没有提高。

B 阈值扫描（纯音乐事件数，非长时 FA/h 推广）：

放宽阈值到 4 可提高片段命中，但音乐事件增加，无法解决当前权衡。阈值升高时事件会合并、中心移动，因此基于事件中心的片段命中并不严格单调；这沿用既有统计口径，不代表某帧接受集合变小。没有据此上线 B。
