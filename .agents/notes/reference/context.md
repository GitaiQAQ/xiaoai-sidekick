## Project status

XiaoAI Sidekick is an experimental, root-level sidecar for the Xiaomi XiaoAI Speaker Pro (LX06). The only tested firmware target is 1.94.13 with the community SSH patch. The project aims to preserve the factory assistant, Mi Home, mesh gateway, and media player, but full factory-feature regression and firmware recovery have not been completed.

The repository contains native application source, web assets, scripts, experimental wake-model tooling, and two checked-in wake-model artifacts. It does not provide a clean-clone process to rebuild a complete flashable firmware image or verify recovery on a new device. See the [root README](../../../README.md) and [tools guide](../../../tools/README.md).

## ROM product-feature reverse engineering (active)

The user set an ongoing goal to reverse engineer every product-facing feature in the LX06 ROM and keep auditable results in Agent Notes. The [coverage ledger](../reports/factory-rom-feature-coverage.md) is the working matrix; it is not a claim of completion. The [protocol report](../reports/factory-protocol-reverse-engineering.md) owns selected message paths. Completion requires every entry point classified and each feature either supported by a traced contract/behavior or explicitly left with evidence gaps. Do not read or publish credentials, device auth data, Mesh keys, user databases, logs or personal content; do not run destructive or state-changing ROM paths.

Recent control/security-chain evidence: touchpad's 8-key DFA calls `sys_ssh_enable`; that script sets a temporary marker and requests Dropbear startup. Dropbear has Bluetooth-work-mode and release-marker gates; its init schema defaults disable password authentication while allowing root login, but current configuration, keys and listener binding remain unknown. `nightmode.set` statically sends all five schedule fields to `cfg_set_string`; commit/durability behavior remains unverified. See the coverage ledger.

Recent parallel review also traced the VoIP init gate: `voip_service` starts only for country CN (empty defaults to CN); `clear_data` deletes `/data/voip` and reboots, so it remains unexecuted. Voiceprint FIFO producer/consumer direction and framing remain unproven; BLE/DLNA reviews found no defensible new handler mappings this pass. See the coverage ledger for gaps.

Recent static closure: the touchpad binary contains an eight-key SSH-enablement DFA, fed only by key-down events and timed out after 60 seconds; a complete match calls `sys_ssh_enable`. The `miio_agent` local router rewrites integer request IDs, forwards by a 32-slot `_to` bitmask, and restores original IDs for matched reverse responses; unmatched reverse messages appear to broadcast, an interpretation still marked as inference. See the coverage ledger for evidence addresses and remaining gaps.
