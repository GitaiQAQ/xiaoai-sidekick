# Report: Second-stage continuous reference diagnosis

2026-11-03，主代理在两项 subagent 任务并行期间复核既有本机数据。没有设备访问、录音、云会话、网络权重修改或部署。

## 方法与边界

使用 `temp/analysis/mfcc-audit/s3-35-levels.json` 的原35句分组，只取其中十个“ARM一级候选存在、二级未确认”组。在既有 `temp/analysis/wake-train/l2-d160/eval.json` 的 `s3-music-pos` 连续参考 margin 上，检查原匹配窗口 `[start−0.3,end+0.5]` 的最小值与 margin<0 帧数；时间尺度100帧/秒。

这是基线二级网络的全录音连续 Mac 参考解码结果。它既没有模拟原厂二级从缓存重置的输入，也没有替换成设备第三十四轮调整后的 FST cost3，不能据此推断原厂二级的实际分数或确认率。minimum margin 本身不作为句命中判定，也不修改既有事件聚合规则。

## 既有对齐诊断复核

读取既有 `temp/analysis/mfcc-audit/alignment-tail-audit.json`，没有重新生成标签：198个纯TTS正例的关键词帧中位数91，无≤16帧源；89个真人正例的中位数42，其中20源≤16帧。真人关键词标签有135帧低于−85dBFS，涉及24源；活动边界外加5帧余量仍有75帧关键词标签。

这表明一些真人强制对齐把完整八状态压成极短路径，另有低电平帧被分配为关键词，值得检查边界监督。它不能证明所有低于−85dBFS的帧都是背景：现有第14句正例RMS约−79.56dBFS，弱声本身也可能更低。训练代理已收到避免用绝对电平一刀切标签的提醒。

当前两级确认仍只有7/35。该诊断没有产生新命中或宣称100%准确率。
